llselect vs the field

llselect against Choices.js, Select2, Tom Select and Slim Select on an identical dataset. Everything runs in your browser; nothing is precomputed. Lower is better. Numbers depend on your machine and browser, so read the ratios, not the absolute milliseconds, and click Run a few times.

What each column measures

  • Init + render - from an empty mount to an interactive widget holding N options, with layout forced. This is where llselect's lazy rendering shows: it builds no option DOM until the popup opens.
  • Open popup - time to open the dropdown once built. The counterpart to Init: whatever a library defers from init lands here. Read the two columns together.
  • Filter - type a query that narrows N options to a few and re-render the matches.
  • Select 1, multi - toggle a single option in a large multi-select. llselect replaces one option node rather than rebuilding the list.

Bundle size

Minified transfer bytes, uncompressed - the same method for every script, fetched live from the CDN, so the ratio is fair (gzip shrinks them all by roughly 3x). Select2 also requires jQuery, listed separately.

Method and caveats

  • Each cell is the median of several runs after two warm-ups (fewer runs at large N). A synchronous reflow is forced inside every timed region, so a library cannot look fast by deferring layout past the timer.
  • Libraries use different rendering strategies, which is the whole point of reading Init and Open together: llselect lazy-renders options when the popup opens; Tom Select caps how many options it renders at once (its own perf strategy); Choices, Select2 and Slim Select render eagerly. None is "cheating" - they trade differently.
  • This benches a plain single / multi select. Select2, Choices and Tom Select also do tagging, remote data, templating and more; that scope is not free and is not measured here.
  • A "-" means the adapter could not perform that operation on the loaded CDN version (an API drift), not that the library is incapable. Tell me which cell so I can fix the adapter.
