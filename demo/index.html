llselect demo

A minimal, framework-agnostic replacement for the native <select>. Build the package first, then serve this folder: 

npm run build
npm run serve   # then open /demo/

Examples

Every capability, live and editable: single / multiple, search, optgroups, tags, select-all, width policies, disabled, custom renderers, i18n and RTL - each with its source.

Benchmark

llselect against Choices.js, Select2, Tom Select and Slim Select on the same dataset: initial render, open latency, filter, and single-item selection. Runs in your browser.
