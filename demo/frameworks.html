llselect demo - framework bindings

llselect is an imperative, framework-agnostic widget: you construct an instance on a mount element, drive it with methods (setItems, setChosenItem(s)), listen through onChange, and call destroy() on teardown. Binding it to a framework is just wiring those three moments to that framework's lifecycle and reactive state - create on mount, sync on change, destroy on unmount.

Everything on this page runs with no build step. View source: a single <script type="module"> pulls real React 18 and Vue 3 straight from a CDN and llselect from its ES-module build (../dist/index.mjs). There is no bundler and no JSX compiler - React is written with htm tagged templates. The same create / sync / destroy pattern applies to Angular, Svelte, Solid and the rest; those need their own compiler, so they are not embedded live here, but the wrapper logic is identical.

sel.setChosenItem('Cherry')   // later, from your own code -> updates the widget
sel.destroy()                 // on teardown: drops document / window listeners

React

A controlled <LlSelect> wrapper: useEffect creates the instance once and returns destroy as cleanup; two more effects push items and the controlled value down. Pick in a widget and the readout updates; click a button and the widget updates - two-way, through React state. 

import { LLSelectSingle, LLSelectMultiple } from 'llselect'
import { useRef, useEffect } from 'react'

function LlSelect({ items, value, multiple = false, onChange, ariaLabel, searchable }) {
  const mountRef = useRef(null)
  const instRef = useRef(null)
  const cbRef = useRef(onChange)
  cbRef.current = onChange                       // always reach the latest onChange

  useEffect(() => {                              // create once; destroy on unmount
    const Ctor = multiple ? LLSelectMultiple : LLSelectSingle
    const inst = new Ctor(mountRef.current, {
      ariaLabel,
      searchable,
      // copy the multi array so parent state never aliases llselect's internal one
      onChange: (v) => { cbRef.current(multiple ? v.slice() : v) },
    })
    instRef.current = inst
    return () => { inst.destroy() }
  }, [])

  useEffect(() => { instRef.current.setItems(items) }, [items])

  useEffect(() => {                              // push the controlled value down
    if (multiple) { instRef.current.setChosenItems(value) } else { instRef.current.setChosenItem(value) }
  }, [value])

  return <div ref={mountRef} />
}

// usage
<LlSelect items={FRUITS} value={fruit} onChange={setFruit} searchable ariaLabel="Fruit" />
<LlSelect items={TOPPINGS} value={picked} onChange={setPicked} multiple ariaLabel="Toppings" />

Vue 3

A v-model component: onMounted creates the instance and onChange emits update:modelValue; watch pushes an outside change back into the widget; onBeforeUnmount destroys it. 

import { LLSelectSingle, LLSelectMultiple } from 'llselect'
import { ref, h, onMounted, onBeforeUnmount, watch } from 'vue'

const LlSelect = {
  props: {
    items: { type: Array, default: () => [] },
    modelValue: { default: undefined },
    multiple: Boolean,
    ariaLabel: String,
    searchable: { type: [Boolean, Function], default: false },
  },
  emits: ['update:modelValue'],
  setup(props, { emit }) {
    const mount = ref(null)
    let inst = null
    onMounted(() => {
      const Ctor = props.multiple ? LLSelectMultiple : LLSelectSingle
      inst = new Ctor(mount.value, {
        ariaLabel: props.ariaLabel,
        searchable: props.searchable,
        // copy the multi array so v-model state never aliases the internal one
        onChange: (v) => { emit('update:modelValue', props.multiple ? [...v] : v) },
      })
      inst.setItems(props.items)
      if (props.multiple) { inst.setChosenItems(props.modelValue ?? []) } else { inst.setChosenItem(props.modelValue) }
    })
    watch(() => props.items, (items) => { inst.setItems(items) })
    watch(() => props.modelValue, (v) => {
      if (props.multiple) { inst.setChosenItems(v ?? []) } else { inst.setChosenItem(v) }
    })
    onBeforeUnmount(() => { inst.destroy() })
    return () => h('div', { ref: mount })
  },
}

// usage
<LlSelect v-model="fruit" :items="fruits" searchable aria-label="Fruit" />
<LlSelect v-model="picked" :items="toppings" multiple aria-label="Toppings" />
