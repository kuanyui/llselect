## Waiting for the owner

1. The two-finger zoom in the presets, `TODO.md` "Two-finger zoom in the presets", the owner's spec in `native-select-scrolling.md` "Two-finger zoom": while the popup is open, `behaviorPresetsOfFirefoxOnWindows` blocks a two-finger zoom everywhere and keeps the popup open; `behaviorPresetsOfChromiumOnWindows` blocks one inside the popup, and at one on the trigger or outside closes the popup and lets the zoom go on; the default leaves every zoom alone. Today the library calls `scrollGestureToBehaviorFn` neither for a touch from the moment a second finger lands nor for a wheel with `ctrlKey`, so a preset cannot see a zoom. Codex Sol and Codex Astra were consulted with a neutral brief, `$S/zoom/consult-zoom-api.md`; `TODO.md` records their answers. Three decisions wait for the owner:
   - The shape: both recommend a separate setting, shape B, `zoomGestureToBehaviorFn: (gesture: LLSelectZoomGesture) => LLSelectZoomGestureBehavior`, over one more kind `'pinch'` in `LLSelectScrollGestureKind`, shape A; both correct B's call frequency to once per two-finger touch and every `wheel` with `ctrlKey`. The agent recommends B.
   - The zone's name: Codex Sol renames `LLSelectScrollGestureZone` to `LLSelectGestureZone`, shared by both groups; Codex Astra keeps it.
   - The first finger of a touchscreen pinch: the Firefox preset closes the popup at a one-finger touch-down outside it, before the second finger lands; keeping the popup open at a pinch needs that close deferred, which changes every one-finger close. Under the owner's principle of MEDIUM-939, the native select decides: in native Firefox on the Windows touchscreen, a first finger held alone outside the popup, then a second finger, shows whether the native popup closes at the first finger. The same principle asks what native Ctrl with a mouse wheel does while the popup is open, since the library cannot tell it from a touchpad pinch.

As far as the agent knows, Chromium sends a touchpad pinch to the page as a wheel with `ctrlKey`, the same event as Ctrl with the mouse wheel; Firefox on Linux is not verified. If the two events cannot be told apart, a preset that blocks the touchpad zoom also blocks Ctrl with the mouse wheel.
